# قصص التاريخ — حكايات صنعت التاريخ

موقع عربي RTL لقناة تاريخية إسلامية، مصمم ليعمل على الهاتف والحاسوب باستخدام HTML وCSS وJavaScript فقط.

## المزايا
- واجهة سينمائية داكنة بلمسات ذهبية.
- أقسام للأفلام والقصص وعن المشروع.
- مولّد برومبتات محلي لسكريبتات التعليق الصوتي والصور والفيديو وخطط الإنتاج.
- لا يحتاج إلى تثبيت حزم أو خادم.
- مناسب للنشر عبر GitHub Pages.

## تشغيل محلي
افتح `index.html` في متصفح حديث. الاتصال بالإنترنت مطلوب لعرض خطوط Google والصور الخارجية.

## النشر على GitHub Pages
1. أنشئ مستودعًا عامًا جديدًا باسم `qisas-al-tarikh` على GitHub.
2. ارفع `index.html` و`README.md` إلى جذر المستودع.
3. افتح Settings ثم Pages.
4. في Build and deployment اختر Deploy from a branch.
5. اختر الفرع `main` والمجلد `/(root)` ثم Save.
6. انتظر اكتمال النشر؛ سيظهر رابط الموقع في صفحة Pages.

## تخصيص مهم
- الصور الحالية من Unsplash للعرض التجريبي؛ استبدلها بصور تملك حق استخدامها أو صور مولدة لك.
- عدّل بطاقات القصص وأضف روابط فيديوهاتك الفعلية.
- الأداة تولّد قوالب نصية داخل المتصفح ولا تتصل بنموذج ذكاء اصطناعي مباشر.
- لا تضع مفاتيح API أو كلمات مرور في ملفات الموقع العامة.
- تحقّق من الروايات التاريخية من مصادر موثوقة قبل النشر.
